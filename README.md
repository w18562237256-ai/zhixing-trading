# 知行 · 主线选股决策 V3

首页收敛为最多两个已确认主线与每条主线一个优先对象，区分最强核心与当前有买点的股票，给出等待条件、触发参考、接受上限、退出参考和风险预算。完整名单默认收起。

大盘均线仅提示风险收缩，不再一票否决强势主线。核心排序由强度排名、成交排名、相对板块表现和近期突破共同决定；支持放量突破与突破后回踩两种观察模型。排序与买点参数均为可验证实现，未经过回测，也不是原作者公开的完整算法。

## 行情

扫描公开行业日线，深入检查最多6个预选板块的A股成分，不是全A逐股扫描。排除不足10只A股的小板块与高度重叠板块。网页更新按钮直接读取东方财富接口，失败保留原快照，保留原获取时间，不显示模拟行情。随站快照按页上日期使用，回踩字段由腾讯同日历史数据补充并核对价格；缺字段不产生回踩确认。

不判断消息预期、批量炸板或实时盘口。网站关闭时不自动更新，不连接账户、不下单。仅用于研究与有条件的交易计划，信号不是买入指令。

## 访问与部署

页面使用PBKDF2与AES-GCM加密，密码不提交到仓库。短密码不能提供可靠保密，持有密码的人可复制解密内容。筛选缓存和导出保存在浏览器端。

GitHub Pages从main根目录部署；网页修改后需重新加密提交index.html。
