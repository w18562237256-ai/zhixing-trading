# 知行 · 东方财富数据接入

网站按主线、核心股与买点生成少量优先观察对象。策略参数未回测，不连接证券账户，不下单。

## 数据通道

- 主通道：GitHub Actions云端采集东方财富公开指数、行业板块、A股成分及前复权日线，计算后加密发布。
- 工作日北京时间15:30、16:30尝试更新；GitHub调度可能延迟，节假日以实际行情日期为准。也可在Actions手动运行。
- 浏览器默认同步云端数据；浏览器直连更新和三项连接检测为备用。公开网页接口不是付费API，不保证稳定性。
- 上游失败会写明失败时间和错误，保留上一快照及原数据日期；部署成功不等于行情采集成功。
- 不将腾讯补充过的历史快照标记成纯东财数据；只有完整东财采集成功才显示东财云端来源。

## 安全与范围

网页以访问密码加密，云端行情包采用RSA-OAEP和AES-GCM。仓库只保存行情加密公钥，解密私钥位于密码加密页面中。单字符密码容易猜到，不能提供可靠保密；持有密码者可复制内容。

扫描返回行业板块日线，深入检查最多6个预选板块的A股成分，不是全A逐股扫描。缺失数据不算信号通过。没有实时盘口、批量炸板或消息兑现分析。

发布方式为GitHub Actions，入口 .github/workflows/eastmoney.yml。
