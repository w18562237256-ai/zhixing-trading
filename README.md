# 知行 · 主线选股雷达 V2

根据市场环境、板块趋势、核心股强度与突破信号筛选A股，展示逐项依据、等待条件和退出参考。已从交易记录工具改为选股工具。

## 行情与范围

- 东方财富公开行业列表和前复权日线；仅使用已收盘数据。
- 扫描全部返回行业板块的趋势，再详细检查前4个预选板块的A股成分；不是全A逐股扫描。
- 排除不足10只A股的细分板块与成分重叠达到80%的板块；缺数据不算通过。
- 点击网页“更新行情并重新选股”直接读取公开接口。关闭网站时不自动刷新，免费接口可能限流或不可用。
- 无实时逐笔、炸板聚类、消息预期判断、账户连接或自动下单。参数未回测，不保证收益。

## 访问

网页使用 PBKDF2-SHA256 与 AES-256-GCM 加密，密码不提交到仓库。持有密码的人能复制解密内容；单字符密码不提供可靠保密。筛选缓存保存在当前浏览器，导出CSV为明文。

GitHub Pages从main根目录部署。修改密码或网页需重新加密并提交index.html。
